# setlist.app v2.1.0 — Feature Documentation

## 1. Product Overview

setlist.app is a lightweight browser-based tool for organizing an Event, its Songs, and the individual Song Details used to describe each part of a Song.

The current structure is:

```text
Event
└── Songs
    └── Song
        └── Song Details
```

Version 2.1.0 combines the multi-song foundation from v2.0.0 with a redesigned navigation and visual system.

---

## 2. Event Management

### Event Name

The user can enter or edit the Event Name.

### Event Date

The user can enter or edit the Event Date.

### Reset Event

Reset returns the Event to its initial state:

- Empty Event Name
- Empty Event Date
- Zero Songs

A confirmation is shown before reset.

---

## 3. Song Management

### Add Song

Creates a new blank Song.

Initial Song state:

- Title: empty
- Base Key: empty
- Song Details: none

The new Song becomes the active Song.

### Select Song

Selecting a Song in the sidebar opens it in the main workspace.

### Edit Song Title

Song Title can be edited directly in the main workspace.

### Edit Base Key

Base Key can be edited directly in the main workspace.

### Reorder Songs

Songs can be moved up or down.

The order is persisted.

### Delete Song

Deletes the selected Song and all Song Details belonging to it.

Confirmation is required.

---

## 4. Song Navigation

The sidebar displays all Songs.

Each Song shows:

- Number
- Title
- Base Key
- Active state

The sidebar is the primary Song navigation mechanism.

The main workspace does not duplicate the complete Song list.

---

## 5. Song Workspace

The main workspace displays only the selected Song.

It contains:

- Song Title
- Base Key
- Song controls
- Song Details
- Add Song Detail
- Export PNG

This keeps the workspace focused.

---

## 6. Song Detail Management

Each Song can contain any number of Song Details.

A Song Detail contains:

- Name
- Color
- Note

### Add

Adds a blank Song Detail.

### Edit

Name and Note can be edited directly.

### Color

The color indicator can be used to cycle through the available section colors.

### Reorder

Song Details can be moved up or down.

### Delete

A Song Detail can be removed independently from the Song.

---

## 7. Notes

Notes belong to individual Song Details.

Examples:

```text
INTRO
Start after 4 bars

VERSE 1
Acoustic guitar

CHORUS
Full band
```

There is no separate Song-level Notes feature.

---

## 8. Light / Dark Mode

The application supports:

- Light Mode
- Dark Mode

Theme switching is available directly in the header.

The selected theme is persisted in the browser.

---

## 9. Actions Menu

The Actions dropdown contains:

### Export JSON

Downloads the complete Event data.

### Import JSON

Loads an Event from a JSON file.

Reset remains outside the Actions dropdown.

---

## 10. JSON Export / Import

JSON operations are Event-level.

The JSON includes:

```text
Event Name
Event Date
Songs
  ├── Song Title
  ├── Base Key
  └── Song Details
      ├── Name
      ├── Color
      └── Note
```

Import supports normalization and legacy single-song migration.

---

## 11. PNG Export

PNG export is Song-level.

One PNG represents one selected Song.

The image includes:

- setlist.app
- Event Name
- Event Date
- Song Title
- Base Key
- Song Details
- Notes
- Section colors
- Author
- Version

### Theme-aware PNG

The PNG follows the currently selected theme:

```text
Light Mode → Light PNG
Dark Mode  → Dark PNG
```

---

## 12. PNG Footer

Every exported Song PNG includes:

```text
setlist.app
Author: josiasebastianj
Version: 2.1.0
```

---

## 13. Persistence

Event data is automatically saved in browser localStorage.

Persisted data includes:

- Event Name
- Event Date
- Song order
- Song Title
- Base Key
- Song Detail order
- Song Detail Name
- Song Detail Color
- Song Detail Note

Theme preference is stored separately.

---

## 14. Initial State

A new/empty Event contains:

```text
Event Name: empty
Event Date: empty
Songs: 0
```

There is no default Song.

There is no default Song Detail.

---

## 15. Responsive / Mobile Features

On mobile:

- Theme toggle remains accessible.
- Actions remains accessible.
- Reset remains accessible.
- Event information remains editable.
- Songs remain selectable.
- Song controls remain available.
- Song Details remain editable.
- JSON import/export remains available.
- PNG export remains available.

---

## 16. Accessibility / Interaction Details

Interactive controls use:

- Buttons for actions
- Labels / accessible names for inputs
- `aria-label` on icon-only controls
- `aria-current` for active Song navigation
- `aria-expanded` for the Actions dropdown
- `aria-haspopup` for the Actions dropdown

The Actions menu can be dismissed with Escape.

---

## 17. Removed / Intentionally Excluded Features

### Song Collapse / Expand

Removed in v2.1.0 because only one Song is shown in the main workspace.

### Song-level Notes

Removed because notes are already attached to each Song Detail.

These removals reduce duplicated interaction and information.
