# setlist.app v2.0.0 — Changelog

## Release

**Version:** 2.0.0  
**Author:** josiasebastianj  
**Baseline:** v1.5.2  
**Release type:** Major release

---

## Added

### Multi-song Event architecture

The application now supports multiple Songs inside one Event.

New hierarchy:

```text
Event
└── Songs
    └── Song
        └── Song Details
```

An Event can now contain any number of independent Songs.

### Song management

Added Song-level:

- Add Song
- Delete Song
- Move Song up
- Move Song down
- Collapse Song
- Expand Song
- Edit Song Title
- Edit Base Key
- Song-level PNG export

### Independent Song Details

Each Song now owns its own Song Details.

Song Details retain the behavior from v1.5.2:

- Add
- Edit
- Delete
- Reorder
- Color
- Note

### Empty Song creation

New Songs start with:

- Empty Song Title
- Empty Base Key
- No Song Details
- Expanded state

There is no default Song Detail.

### Event-level JSON

JSON export/import now covers the complete Event:

- Event metadata
- All Songs
- All Song Details

### Legacy data migration

Added migration/normalization support for the previous v1.5.2 single-song data structure.

Existing single-song data can be represented as an Event containing one Song.

### PNG export footer

Added the following information to Song PNG exports:

```text
Author: josiasebastianj
Version: 2.0.0
```

The footer is included in the generated image and its height is accounted for during export.

### Application footer

Added the same author and version information to the application UI footer.

---

## Changed

### Data model

Previous:

```text
Song
└── Song Details
```

Now:

```text
Event
└── Songs
    └── Song
        └── Song Details
```

### PNG export scope

PNG export is now Song-level.

Each exported image represents one specific Song rather than an entire multi-song Event.

The exported Song image still includes the Event Name and Event Date as header information.

### Reset behavior

Reset now restores the complete Event to the initial state, including removing all Songs and their Song Details.

### Initial state

The application now starts with:

- Default Event Name
- Default Event Date
- Zero Songs

This is also the Reset state.

- Song Title editing
- Base Key editing
- Song Detail editing

- Song Detail reorder
- Song Detail deletion
- Event Name

## Versioning

v2.0.0 is a major version because the underlying application data model has changed from a single Song to a multi-song Event.

The author/version footer is included within this release and does not create an additional version.
